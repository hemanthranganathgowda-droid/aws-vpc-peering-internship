AWS VPC Peering
& Secure Connectivity

A hands-on AWS networking project demonstrating private communication between two Virtual Private Clouds through VPC Peering, route tables, security groups, and connectivity testing.

Explore Architecture View Project Report

Project Overview

The objective was to establish private network communication between two separate Amazon VPCs while controlling traffic through routing and security-group rules.

☁️ VPC Networking

Created two VPCs with non-overlapping CIDR ranges and configured public and private subnets.

🔗 VPC Peering

Established a peering connection and configured routes for private communication between VPCs.

🛡️ Security Controls

Configured security groups to restrict SSH and ICMP traffic to the intended source addresses.

🧪 Connectivity Testing

Tested communication in both directions and verified the effect of temporarily blocking ICMP traffic.

AWS Architecture

The lab used a bastion host in the public subnet of VPC A and two private application instances across the peered VPCs.
